## Automação futura

- **Meta.** Verifique Instagram Insights para conta profissional e Page Insights para a Página. Identifique os ativos, o responsável autorizado, o modelo de login, as permissões e a cobertura das métricas vigentes. [Visão geral do Meta Insights](https://developers.facebook.com/docs/insights/overview/) · [Endpoints documentados](https://developers.facebook.com/docs/insights/references/)
- **YouTube.** Verifique a YouTube Analytics API com OAuth em leitura e os relatórios aceitos para o canal confirmado. Para coleta em volume, avalie as diferenças da Reporting API e seus requisitos. [Exportação pelo Studio](https://support.google.com/youtube/answer/9717005?hl=pt-BR) · [Autorização das APIs](https://developers.google.com/youtube/reporting/guides/authorization)
- **TikTok.** A Display API documenta contadores por vídeo, incluindo visualizações, curtidas, comentários e compartilhamentos. Retenção e tempo médio não constam entre os campos documentados dessa consulta. Mantenha os relatórios do Studio para métricas que a integração autorizada não entregar. [TikTok Analytics](https://ads.tiktok.com/business/library/HowTo_Guide_From_Custom_Identity_to_TikTok_FIRST.pdf) · [Campos da consulta de vídeos](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-query)

Ao avaliar uma integração recorrente, confira os campos e a granularidade com uma exportação real da mesma conta e janela. Para contadores cumulativos, guarde a data da coleta e considere os intervalos entre capturas e eventuais correções da plataforma. Só classifique uma fonte como integrada depois de uma leitura autorizada e verificada.
